# **RastaAsian Sanctuary**

A fully custom **Single‑Page Application (SPA)** built with hand‑crafted HTML, CSS, and vanilla JavaScript.  
Designed and developed by **RastaAsian (Desiree)** — blending UX/UI design, front‑end development, and immersive gothic branding into a calm, ND‑friendly digital experience.



## 🚀 **Features**

### 🖤 **Custom SPA Architecture**
The Sanctuary runs inside a unified **SPA shell**, featuring:
- Dynamic page loading (no full reloads)  
- Smooth fade transitions between sections  
- Persistent background audio  
- Zero iframes  
- Zero frameworks — pure vanilla JavaScript  

### 🌙 **Immersive Gothic Theme**
A fully hand‑designed aesthetic:
- Gothic ornaments and dividers  
- Soft glows and subtle animations  
- Sanctuary‑themed typography  
- Consistent visual identity across all pages  

### 📱 **Mobile‑Perfect Navigation**
A custom hamburger menu with:
- Smooth open/close animation  
- Auto‑close on link click  
- Fully responsive layout  
- Seamless SPA integration  

### 🎧 **Persistent Music Orb**
A floating audio orb that:
- Plays continuously across navigation  
- Never restarts thanks to SPA architecture  
- Includes play/pause toggle  
- Features a subtle visualizer  

### 🧩 **Modular Page System**
Each page is built as a **partial** and dynamically injected into the SPA:
- Home  
- About  
- Games & Streams  
- Setup & Gear  
- Events  
- Services & Pricing  
- Contact

## 🛠️ **Tech Stack**
- **HTML5** — semantic, clean, hand‑written  
- **CSS3** — custom gothic theme, animations, responsive layout  
- **JavaScript (Vanilla)** — SPA routing, transitions, audio control  
- **No frameworks** — no React, Vue, Bootstrap, or templates  
- **No generators** — every component is hand‑crafted
