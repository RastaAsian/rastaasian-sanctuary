# RastaAsian Sanctuary  
A multi‑page gothic‑themed website built with custom HTML, CSS, and JavaScript.  
Designed and developed by RastaAsian — blending UX/UI, front‑end development, and immersive branding.

---

## 🚀 Features

### 🌐 Multi‑Page Layout  
Fully responsive pages including:
- Home  
- About  
- Games & Streams  
- Setup & Gear  
- Events  
- Services & Pricing  
- Contact  

### 📱 Mobile Navigation (JavaScript Powered)  
A custom hamburger menu built with vanilla JavaScript:
- Smooth open/close animation  
- Auto‑close on link click (premium UX)  
- Consistent across all pages  
- No frameworks, no templates — fully hand‑coded  

### 🎨 Custom Gothic Theme  
- Hand‑crafted CSS  
- Glow accents, gothic dividers, and themed typography  
- Responsive grids and cards  
- Brand‑aligned visuals across the entire site  

### 🎧 Optional Persistent Audio  
The wrapper page supports continuous background music using an iframe‑based layout.
